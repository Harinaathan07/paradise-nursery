# Paradise Nursery Shopping Application

An e-commerce React web application for Paradise Nursery, an online plant shop offering indoor, aromatic, and medicinal plants.

## Features
- Landing page introducing Paradise Nursery with a "Get Started" navigation button.
- Categorized plant listings with prices, descriptions, and plant images.
- Interactive shopping cart managed with Redux Toolkit.
- Cart features including dynamic total quantity badge, item increment/decrement, removal, and live total cost calculation.
